04 / 10
● WHY IT MATTERS

LLM 성능을 정하는 두 개의 숫자

① 메모리 용량

“모델이 들어가는가”

LLM은 실행되는 동안 모델 전체를 메모리에 올려 둡니다. 맥은 CPU와 GPU가 메모리를 함께 쓰는 통합 메모리 구조라, 96GB의 상당 부분을 그대로 AI 모델에 내줄 수 있습니다.

② 메모리 대역폭

“얼마나 빨리 말하는가”

글자(토큰)를 하나 만들 때마다 모델을 메모리에서 한 번 훑어 읽습니다. 그래서 1초에 읽을 수 있는 양, 즉 대역폭이 곧 답변 속도의 상한이 됩니다.

🧮 어림 계산 · 1.2TB/s ÷ 모델 40GB ≈ 초당 최대 약 30토큰 (이론상 상한이며 실제 속도는 더 낮습니다). 일부만 골라 쓰는 MoE 모델은 읽는 양이 적어 훨씬 빠릅니다.
어려운 용어 두 개만 기억하시면 됩니다. 통합 메모리는 "그릇의 크기", 대역폭은 "그릇에서 꺼내는 속도"입니다. 어림 계산은 이론상 최대치이므로 실제 속도는 직접 측정해 보는 게 정확합니다.

● LOCAL STACK

로컬 LLM을 돌리는 도구들

입문 추천

Ollama · LM Studio

설치하고 모델을 내려받으면 바로 대화할 수 있습니다. 둘 다 내 맥 안에서 API 서버를 열어 주기 때문에 옵시디언 같은 다른 앱이 연결할 수 있습니다.

애플 실리콘 최적화

MLX · llama.cpp

MLX는 애플이 만든 머신러닝 도구로, 맥의 통합 메모리 구조에 맞춰져 있습니다. 속도를 더 끌어내거나 직접 미세조정을 해 보고 싶을 때 씁니다.

의미 검색

임베딩 모델

글의 의미를 숫자로 바꿔 주는 작은 모델입니다. “비슷한 내용의 노트 찾기”를 가능하게 합니다. 한국어 지원 여부를 꼭 확인하세요.

연결 고리

옵시디언 플러그인

로컬 모델 연결을 지원하는 커뮤니티 플러그인으로 볼트 안에서 바로 질문하고, 노트 사이의 관련성을 찾을 수 있습니다.

처음에는 Ollama나 LM Studio 하나만 설치해도 충분합니다. MLX와 llama.cpp는 익숙해진 뒤에 살펴봐도 됩니다. 옵시디언 플러그인은 종류가 많고 자주 바뀌므로, 설치 전에 로컬 모델 지원 여부를 확인하세요.

이 구조의 중심은 AI가 아니라 옵시디언 볼트입니다. 로컬 모델과 클로드 코드는 모두 같은 마크다운 파일을 읽고 씁니다. 그래서 어느 한쪽 서비스가 바뀌어도 내 지식 자산은 그대로 남습니다.

● ROUTING RULES

어떤 일을 어디에 맡길까

작업맡길 곳이유
미공개 원고 초고 피드백로컬원고가 외부로 나가지 않음
볼트 노트 요약 · 태그 · 연결 찾기로컬반복이 많아 API 비용 부담이 큼
개인 일기 · 메모 기반 회고로컬가장 민감한 개인정보

자료 조사 · 사실 확인 · 최신 정보Claude Code웹 검색과 높은 정확도가 필요

기준은 단순합니다. 민감하거나 반복적인 일은 로컬, 어렵거나 최신 정보가 필요한 일은 클로드 코드. 이 표를 볼트 안에 규칙 문서로 적어 두면, 매번 고민하지 않아도 됩니다.

● SETUP · 4 STEPS

오늘 시작하는 4단계

1

Ollama 설치 + 모델 하나 받기

중형 모델 하나로 시작해 속도와 품질을 직접 확인합니다.

2

옵시디언에 로컬 모델 연결

플러그인 설정에서 주소를 내 맥(localhost)으로 지정합니다.

3

볼트 폴더에서 Claude Code 실행

CLAUDE.md에 볼트 구조와 작업 규칙을 적어 둡니다.

4

업무 분담 규칙 문서화

8쪽의 표를 볼트에 노트로 남기고 쓰면서 고쳐 갑니다.

# 1) 모델 내려받기 (모델 이름은 예시)
$ ollama pull <모델이름>

# 2) 터미널에서 바로 대화해 보기
$ ollama run <모델이름>

# 3) 다른 앱이 연결하는 주소
http://localhost:11434

# 4) 볼트 폴더에서 클로드 코드 실행
$ cd ~/내볼트 && claude
처음부터 완벽하게 꾸미려 하지 말고, 모델 하나와 플러그인 하나로 시작하세요. localhost는 "이 컴퓨터 자신"이라는 뜻이라, 이 주소로 연결하면 데이터가 밖으로 나가지 않습니다.

민감한 일은 내 맥에,
어려운 일은 프론티어 모델에.

✅ 결과는 검증

로컬 모델도 틀린 사실을 말합니다. 중요한 내용은 꼭 확인하세요.

✅ 라이선스 확인

모델마다 상업적 이용 조건이 다릅니다. 받기 전에 확인하세요.

✅ 작게 시작

모델 하나, 플러그인 하나, 규칙 노트 하나부터 시작합니다.

정리하면 세 줄입니다. 지식은 볼트에, 민감한 일은 맥에, 어려운 일은 프론티어 모델에. 마지막으로 로컬 모델의 답도 항상 검증하고, 모델 라이선스를 확인하는 습관을 권합니다.
